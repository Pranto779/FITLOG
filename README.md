Name: FITLOG

Description:
FITLOG is a workout library project. Here users can explore exercises and make their own workout plan.

Technologies:

1. Next.js
2. React
3. TypeScript
4. Tailwind CSS
5. DaisyUI
6. Context API
7. React Icons
8. React Toastify

Features:

1. Users can see different workout exercises with their details
2. Exercises can be added to today's workout plan
3. Users can save exercises for later
4. Saved and planned exercises can be removed
5. Users can sort exercises by duration, calories and rating
6. There is a separate details page for each exercise
7. The website is responsive for mobile, tablet and desktop
